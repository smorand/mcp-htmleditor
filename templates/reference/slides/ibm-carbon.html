Fonctionnalités · Slide 02 / 09

Capacités clés

Les grandes fonctionnalités qui structurent le produit IBM Bob.

Agentic Chat
Interface principale multi-étapes

Bob lit des fichiers, raisonne sur l'ensemble du codebase et implémente des features de façon autonome sur plusieurs fichiers à la fois.

Literate Coding
Code depuis le langage naturel

Écrire des instructions en français directement dans le fichier source. Bob génère le code et affiche un diff inline pour révision avant acceptation.

Code Review /review
Revue assistée par IA

Détecte les problèmes potentiels (complexité cyclomatique, maintenabilité) et propose des refactorisations via le Bob Findings panel.

Subagents
Parallélisation des tâches

Bob décompose une tâche complexe en workstreams parallèles. Chaque sous-agent tourne dans son propre contexte isolé, résume ses résultats au parent.

Marketplace
Écosystème extensible

Serveurs MCP et modes custom contribués par la communauté. Installation en quelques clics depuis l'interface Settings de Bob.

Bobalytics
Analytics Enterprise

Tableau de bord d'adoption, Bob Factor (impact codebase), suivi des dépenses en Bobcoins par équipe. Réservé au plan Enterprise.

Le système de Modes

Chaque mode est une personnalité spécialisée qui adapte le comportement, les outils autorisés et les instructions de Bob.

Mode Rôle Outils Profil cible
Agent Écriture et modification de code, correction de bugs Lecture, écriture, commandes, agents Développeur
Plan Architecture, spécifications, plan d'implémentation Lecture, écriture (limité) Dev Fonctionnel
Ask Questions, explications, compréhension du code Lecture seule Fonctionnel
Advanced Capacités étendues + MCP, intégrations complexes Tous outils + MCP Développeur
Orchestrator Coordination de sous-agents sur tâches longues Spawn subagents Développeur
Custom Modes Personnalité sur-mesure (Product Manager, Docs Writer…) Configurables par mode Tous profils
Rules vs. Modes
Les Rules (.bob/rules/) s'appliquent à toutes les conversations, peu importe le mode. Les modes définissent le comportement et les outils pour une session spécifique. Les deux mécanismes sont complémentaires et versionnés en git.

Infrastructure IA · Slide 06 / 09

LLMs & Routing

Bob utilise plusieurs Large Language Models. La sélection est automatique et transparente — l'utilisateur ne choisit pas le modèle.

Complexité de la tâche
Tâches simples vs complexes

Questions rapides → modèles légers, économiques. Implémentation multi-fichiers → modèles puissants avec raisonnement profond.

Capacités requises
Forces spécifiques

Génération de code, raisonnement logique, compréhension de doc, vision (analyse d'images)… chaque tâche est routée vers le modèle le plus adapté.

Taille du contexte
Grands codebases

Les projets volumineux nécessitent des modèles avec une fenêtre étendue. Bob route automatiquement vers ces modèles sans configuration manuelle.

Optimisation des coûts
Bobcoins = budget prévisible

Les tokens sont convertis en Bobcoins — une unité standardisée indépendante du modèle. Les admins suivent la dépense par équipe via Bobalytics.

Capacité Vision
Bob peut analyser des captures d'écran et images. Le mode Carbon React est spécialement conçu pour convertir des maquettes / screenshots en composants React Carbon Design System.

Valeur métier · Slide 07 / 09

Profils non-développeurs

Bob n'est pas réservé aux ingénieurs. Le système de modes et le langage naturel ouvrent ses capacités à tous les profils.

ProfilMode recommandéCe que Bob apporte
Product Manager / PO Custom PM mode Transforme une idée floue en user stories, MVP, success metrics et roadmap en langage naturel.
Business Analyst Ask Interroge la logique métier d'une application sans toucher au code. Produit des spécifications fonctionnelles.
Technical Writer Custom Docs mode Lit le code et génère / met à jour la documentation Markdown automatiquement.
Security / Compliance Custom Security mode Analyse le code sous angle conformité et produit des rapports standardisés.
Designer / UX Carbon React Convertit une maquette ou screenshot en composants React Carbon — sans écrire de code.
Manager / DSI Bobalytics Dashboard d'adoption, d'impact et de coûts par équipe — sans jamais ouvrir l'IDE.
Clé d'accessibilité
Les équipes techniques configurent Rules + AGENTS.md une fois. Les profils fonctionnels bénéficient automatiquement d'un Bob déjà "formé" au contexte projet — sans configuration manuelle.

Gouvernance · Slide 08 / 09

Plan Enterprise

Fonctionnalités dédiées aux organisations : gestion des équipes, contrôle des dépenses et observabilité complète.

Gestion des rôles
User & Admin

User : accès Bob dans les limites de dépenses de l'équipe.
Admin : gestion des utilisateurs, équipes, dashboard administration.

Spending limits
Contrôle des coûts par équipe

Les admins configurent des plafonds de Bobcoins par équipe pour maîtriser les coûts d'usage de l'IA à l'échelle de l'organisation.

Bobalytics
KPIs d'adoption

Adoption rate — taux d'utilisation par équipe.
Bob Factor — contribution réelle au codebase.
Bobcoin spend — coûts quotidiens et tendances.

Premium packages
Add-ons spécialisés

Extensions optionnelles avec des capacités spécifiques. Attribution de seats par package et par utilisateur contrôlée par les admins.

Sécurité des données
Bob ne collecte jamais votre code ni vos prompts dans sa télémétrie. Données interdites : SPI, PHI, données financières sensibles, code export-controlled Red/Gray.

Démarrage rapide · Slide 09 / 09

L'écran d'accueil Bob IDE

Trois actions essentielles pour démarrer immédiatement depuis la page Welcome de Bob IDE.

① New File… — Créer un fichier / dossier
Démarre un nouveau projet depuis zéro, directement dans Bob IDE, sans passer par l'explorateur de fichiers système.
② Barre de chat — Lancer une conversation
Utilisez @ pour le contexte fichier, / pour les commandes, et le langage naturel pour tout le reste.
③ Clone Git Repository… — Cloner un repo
Importe un dépôt GitHub/GitLab. Bob génère automatiquement l'AGENTS.md et est prêt à travailler dessus immédiatement.
