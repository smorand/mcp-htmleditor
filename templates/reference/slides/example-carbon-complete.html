Architecture technique

Sept composants, un seul point d'entrée pour le développeur, une exécution isolée et entièrement tracée.

Architecture cible

IDE / Chat Point d'entrée développeur
→
Orchestrateur Plans, budgets, reprise
→
LLM Router Quotas, coût, repli
↓
Registry MCP Catalogue serveurs et outils
→
Agent Worker x N Exécution isolée, worktree git
⇢
Observabilité Traces OTel, coût, audit
↓
Stockage artefacts Diffs, rapports, journaux
Isolation par défaut
Chaque agent worker travaille dans son propre worktree git et n'accède aux outils qu'à travers le registry MCP, ce qui rend chaque action rejouable et auditable.
