# US-0037: `outline` and `get_slide` tools

> Files touched: 5

## Objective

Exposes the two read operations on the agent tool surface with the same results and the same error text as the command line.

## Requirements covered

- SPEC-0007/FR-NEW-001 (partial: tool surface `outline(file)`): WHEN an agent or a user asks for the `outline` of a file THE Editor SHALL return a JSON object describing the file structure without any image data.
- SPEC-0007/FR-NEW-002 (partial: tool surface `get_slide(file, id)`): WHEN an agent asks for `get_slide` with a slide id THE Editor SHALL return the HTML of that slide only, with every image whose source is a data address longer than 1 000 characters replaced by the reference `data:ref:img-N`.
- SPEC-0007/FR-NEW-016 (partial: outline and get_slide only): The Editor SHALL give the same result for each of these operations through the command line and through the agent tool surface, the tool surface returning an error whose message is the command line error line without its `error: ` prefix.

## Independent Test

`make test ARGS='-k deck_tools_mcp'`: through an in process `fastmcp.Client(mcp)`, `outline` on DECK-EI returns an object equal to the JSON printed by `mcp-htmleditor outline`; `get_slide` of `slide-3` returns the HTML with `data:ref:img-1`; `mcp-htmleditor skill-audit` reports both names in the core (the audit is SPEC-0006's independent check).

## Design excerpt

### Decisions
- DEC-009 (SPEC-0007): "`deck/` is a service layer; `cli.py` and `mcp_server.py` only parse input, call it, and print or return. `DeckError` becomes `error: <msg>` plus exit 1 on the command line and `ToolError(<msg>)` on the tool surface."
- DEC-015 (SPEC-0007): "JSON output is compact with `ensure_ascii=False`; `file` echoes the caller's string." The tool returns the dict, the command prints the JSON of the same dict.
- Skill rules: "no stdout in the MCP process (services return values, only `cli.py` echoes); `trace_span` on tool operations (`category.operation` names)".

### Data model
No new shape. `outline` returns the object of US-0035; `get_slide` returns the HTML string of US-0036.

### Contracts
```python
@mcp.tool() def outline(file: str) -> dict[str, Any]
@mcp.tool() def get_slide(file: str, id: str) -> str            # noqa: A002 (spec name)
```
Each body runs inside `trace_span("mcp.outline")` / `trace_span("mcp.get_slide")`, calls `deck.read.outline` / `get_slide`, and converts `DeckError` into `fastmcp.exceptions.ToolError(str(exc))` (message without the `error: ` prefix).

Lines added to the `## Tools` section of `skill/core.md` (shape `- <name>: <description>`):
- `- outline: Read the structure of a file (charter, slides, headings) without any image data.`
- `- get_slide: Read the HTML of one slide, large images replaced by data:ref:img-N.`

README: add the two tools and the two commands (`outline`, `get-slide`) to the tools/commands lists.

Error text equality: for every error of `outline` and `get_slide`, the tool error message equals the command stderr line without `error: `. The tools write nothing on the process stdout.
