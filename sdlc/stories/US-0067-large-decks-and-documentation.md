## Objective

Prove the 30 second budget on 40 slide presentations (full analysis, one slide report, with images), document the feature everywhere it must be documented, and close the spec with the full acceptance set green.

## Requirements covered

- SPEC-0008/FR-NEW-007: A `--report-only` analysis of a presentation of 40 slides SHALL finish in less than 30 seconds on a typical workstation.
- SPEC-0008/FR-NEW-003 (partial: a single slide report on a 40 slide deck): WHEN a user passes `--report` THE Editor SHALL also print the layout problems of the rendered slide, then a final line, and exit with status 1 when at least one problem is found.
- SPEC-0008/FR-NEW-004 (partial: a full analysis of a 40 slide deck): WHEN a user passes `--report-only` THE Editor SHALL analyse every slide of the presentation, write no picture, print the problem lines and the final line, and exit with status 1 when at least one problem is found.

## Independent Test

`make check`: the whole SPEC-0008 acceptance set is green; `render <40 slide deck> --report-only` ends in less than 30 seconds with `report: OK`; `README.md` documents `render` and `make install-browser`.

## Acceptance tests

> 100% must pass, run through `make check` (or the project target). Never run test files ad hoc.

Fixtures of the spec (verbatim):

DECK-EI: an Euro-Information presentation of 8 slides `slide-0` to `slide-7` with no layout problem. DECK-MED: a
medical presentation of 6 slides whose `slide-2` has class `slide dark`. DOC-PERSO: a document. The machine running the tests has Segoe UI or Calibri installed, so DECK-EI and DECK-MED report no font problem. Where a test needs a defect, it states the defect.

Fixtures are generated by `tests/render_support.py` (US-0060) from the SPEC-0007 helpers in `tests/deck_support.py` (`build_deck`, `deck_med`, `doc_perso`, `run_cli`, `call_tool`), never committed and never read from `~/.config`. DECK-EI is `build_deck("ei", EI_TITLES)` with 8 titles and no big image. DECK-MED is `deck_med()` with the article of `slide-2` given `class="slide dark"`. DOC-PERSO is `doc_perso()`. The output directory is redirected with `monkeypatch.setattr(tempfile, "tempdir", str(tmp_path))`. Browser tests carry `@needs_chromium`. On a machine without Segoe UI and Calibri the EI font stack still ends with Arial (`templates/bootstrap/slides-ei-empty.html:31`), which keeps DECK-EI free of a `font` problem.
