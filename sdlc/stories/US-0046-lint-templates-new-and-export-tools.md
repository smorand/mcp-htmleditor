## Objective

Finishes the tool surface: `lint`, `list_templates`, `new_file` and `export` return what the command line gives, with the same error text. The server now lists 15 tools and the skill core names all of them. Closes SPEC-0007.

## Requirements covered

- SPEC-0007/FR-NEW-012 (partial: tool surface `lint(file)`): WHEN an agent or a user runs `lint` on a file THE Editor SHALL report every problem found and a verdict, and exit with status 1 when at least one problem is an error.
- SPEC-0007/FR-NEW-015 (partial: tool surface): WHEN an agent calls `list_templates`, `new_file` or `export` THE Editor SHALL give the results of the command line `templates`, `new` and `export`.
- SPEC-0007/FR-NEW-016 (partial: lint, list_templates, new_file and export): The Editor SHALL give the same result for each of these operations through the command line and through the agent tool surface, the tool surface returning an error whose message is the command line error line without its `error: ` prefix.

## Independent Test

`make check`: through `fastmcp.Client(mcp)`, `list_templates` returns the 8 keys in order, `new_file` creates `a.html`, `export` writes a real `a.docx`; the server lists 15 tools whose names equal the names in the `## Tools` section of `skill/core.md`, and `mcp-htmleditor skill-audit` exits 0.

## Design excerpt

### Decisions
- DEC-009 (SPEC-0007): service layer; `DeckError` becomes `ToolError(<msg>)`; the tool never prints.
- DEC-015 (SPEC-0007): JSON compact; the `lint` tool returns the same object as `lint --json`.
- Section 5.2: "Seven existing tools plus `get_skill` plus the seven new ones make 15 (SPEC-0001 FR-009 is not edited)."
- Skill rule: `trace_span("mcp.<tool>")` on each tool.

### Data model
`lint` returns `{"problems":[...],"errors":n,"warnings":n}`; `list_templates` returns `[{"key","description"}]`; `new_file` returns `{"ok":true,"file":<file>}`; `export` returns `{"ok":true,"output":<output>,"warnings":[...]}`.

### Contracts
```python
@mcp.tool() def lint(file: str) -> dict[str, Any]
@mcp.tool() def list_templates() -> list[dict[str, str]]
@mcp.tool() def new_file(template: str, file: str) -> dict[str, Any]
@mcp.tool() def export(file: str, format: str, output: str) -> dict[str, Any]   # noqa: A002 (spec name)
```
Each body runs in `trace_span("mcp.<tool>")`, calls `lint_file`, `template_listing` (import it under another name than `templates.list_templates`), `create_file`, `export_file`; `DeckError` becomes `ToolError(str(exc))`. `new_file` never serves; `export` returns `warnings` from the outcome. Errors are the command line lines without the `error: ` prefix.
Lines added to `## Tools` in `skill/core.md`:
- `- lint: Check a file against the structure and charter rules; returns problems, errors and warnings.`
- `- list_templates: List the 8 template keys with their description.`
- `- new_file: Create a file from a template key; refuses an existing target.`
- `- export: Export a presentation to pptx or a document to docx.`
The final tool set (15): start_server, stop_server, get_status, open_file, update_start, update_end, layout_arch_diagram, get_skill, outline, get_slide, patch, lint, list_templates, new_file, export.
README: usage of the seven operations (commands and tools), the note that `new` and `export` errors are now the English `error: ...` lines. `.agent_docs/agent-editing.md`: consolidate formats, engine rules and gotchas written by US-0036 and US-0039.
