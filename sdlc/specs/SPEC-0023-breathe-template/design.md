## 2. Approaches

### Chosen: a new charter that keeps the `med-*` class vocabulary, plus a painted PPTX pass inside the exporter

The `breathe` key gets its own registry entry, its own marker `--breathe-ice`, its own lint tables and its own
export path. The CSS custom properties and classes of the source template stay `--med-*` / `med-*`. Detection
gives the page declaration the last word, so a deck declaring `medical` stays medical whatever classes it holds,
and a deck declaring `breathe` is Breathe even though its styles carry `--med-teal`. The exporter keeps its flow
engine for every slide (that is the degraded result) and, for Breathe decks only, repaints each slide from
Chromium measures when the browser is available.

Pros: the 23 layouts and the WCBIP deck move by one attribute; no medical behaviour changes; the painted result
is the one Lamya already validated on PowerPoint. Cons: the `med-` prefix is shared by two charters, so the
foreign class tables cannot exclude one from the other by prefix (handled by explicit names, DEC-004).

### Rejected: migrate the vocabulary to a `br-` prefix (DEC-002)
A rename of about 180 classes in the template, the deck and the tools, for no visible gain, the day before a talk
must be built; it would also break the one attribute switch of FR-NEW-020.

### Rejected: a separate post export command, as today (DEC-005)
Keeps two steps the user forgets, and the editor's export button and the agent tool would give an unfinished PPTX
(FR-NEW-022).

### Rejected: a picture per slide (DEC-005)
Faithful but not editable (NFR-005).

## 4. Data model

No persisted concept. The deck carries:
- `<html data-doc-type="presentation" data-doc-template="breathe">`;
- in `:root`, the marker `--breathe-ice:#E7F7FF` next to the `--med-*` tokens;
- the decoration block `/* breathe:assets:begin */ ... /* breathe:assets:end */` in its `<style>`: one rule
  `.med-bg-<preset>-s<N> { background-image:url(<data URI | assets/bg-...png>); }` or
  `.med-ico-<glyph>-<variant> { background-image:url(...); }` per class used by a slide, alphabetical;
- `<img data-asset="<file name>" src="<data URI | assets/<file name>>">` for catalogue or deck pictures.

### 5.1 Command line
- `mcp-htmleditor templates`: 9 keys, `breathe` after `medical`.
- `mcp-htmleditor new breathe <file>`.
- `mcp-htmleditor breathe-inline <file> [--link]`: stdout one line (FR-NEW-006, FR-NEW-007); errors
  `error: <message>` on stderr, exit 1 (FR-NEW-008).

  `make check-generated` (adds `tools/sync_breathe_layouts.py --check`).

### 5.2 Python
- `export/charters.py`: `BREATHE_MARK = "--breathe-ice"`; `is_breathe(declared: str | None, css: str) -> bool`
  returns `declared == "breathe" or (declared != "medical" and BREATHE_MARK in css)`.
- `breathe/inline.py`: `embed_assets(file: str, *, link: bool) -> InlineOutcome` (`classes`, `pictures`,
  `copied`, `folder`, `size_kb`); raises `DeckError` with the FR-NEW-008 texts.
- `export/pptx_paint.py`: `paint_deck(prs, html_path, report) -> None`; `PaintUnavailable(reason)`;
  measure script `MEASURE_JS`; `Painter`.
- `http_server.py`: `_serve_deck_file(raw_path: str) -> None`; `DECK_FILE_TYPES` (suffix -> media type).

### 5.3 HTTP
`GET /<path>` not matched by an editor route: after the request gate, the file next to the open deck, `200`
with its media type and `Cache-Control: no-store, must-revalidate`, else `404 {"error": "Not found"}`.

### 5.4 Messages (verbatim from the spec)
`Breathe deck exported without the rendered finish (<reason>). Install the browser with: make install-browser`
with `<reason>` one of `Chromium is not installed`, `the render extra is not installed`,
`Chromium could not start: <first line>`.

## 7. Compatibility and risks

- Medical decks: the detection rule only adds branches taken when the declaration is `breathe` or the marker is
  present without a medical declaration; the golden fingerprints of the ten templates are the guard (E2E-044).
- The `med-` prefix is foreign to Carbon and Euro-Information already; Breathe classes in those decks keep
  giving L007.
- Painted export needs the render extra and Chromium; the degraded path is always written first, so a failure of
  the measure can never lose the PPTX (NFR-006).
- LFS: a clone without git-lfs gets pointer files in `templates/assets/breathe/`; `make install` copies the
  templates folder, so the installed catalogue would be pointers. Risk recorded in the report; `git lfs install`
  is a prerequisite documented in `.agent_docs/makefile.md`.
- Fonts: the painted export writes Georgia and Trebuchet MS (present on Windows and macOS); on a Linux CI the
  measures use substitutes, so painted PPTX are not golden recorded (structure is tested instead).

## 8. Security design

Threat: a local process (any web page open in the browser, or another program) asks the editor server for a
file. Sink: file read answered on the socket. Controls, in order (DEC-008):
1. The existing request gate runs before dispatch (`http_server.py:278`): host and origin checks, ambiguous
   headers. A deck file is never looked at for a refused request (E2E-SEC-006, channel: answer bytes compared
   with the file bytes).
2. Editor routes are matched first; the deck file route is the last branch before `Not found`.
3. The raw path (query dropped) is percent decoded once (`urllib.parse.unquote`); a NUL, a trailing `/`, a first
   segment reserved by the editor (`static content content-frame status export requests review health
   arch-layout`) or a hidden segment (starts with a dot, not `.` or `..`) refuses.
4. Lexical normalisation (`posixpath.normpath` of the decoded path without its leading slashes); a result that
   starts with `..` (climbs above the folder) or is absolute refuses. Then `base = Path(current_file).resolve()
   .parent`, `target = (base / normalized).resolve()`; refuse unless `target.is_relative_to(base)`, no segment of
   `target.relative_to(base)` is hidden, and `target.is_file()`; links are resolved before the check
   (E2E-SEC-003).
5. Allow list on both the requested suffix and the resolved suffix (`DECK_FILE_TYPES`, case insensitive).
6. Every refusal is the plain `Not found` answer and the warning `Refused GET <raw path>: not served`.
7. Every served deck file carries `X-Content-Type-Options: nosniff`; an SVG also carries
   `Content-Security-Policy: sandbox; script-src 'none'` so it never runs scripts in the editor's origin
   (E2E-SEC-010, E2E-071).
Exploit tests run against a real server through raw sockets (`tests/http_support.exchange`), absence of effect
read by searching the answer bytes for `TOP-SECRET-42` and by checking the server log line. Nothing new is traced
with content; the span `http.deck_file` carries the suffix and the status only.

## 10. Decisions log

- **DEC-001:** charter key `breathe`, marker `--breathe-ice`, detection `declared == "breathe" or (declared !=
  "medical" and marker in css)`, one function in `export/charters.py` used by the deck, the exporter, and mirrored
  in `detectTemplate`. **Obliged by:** FR-NEW-003, FR-NEW-019. **Rationale:** the declaration wins, so existing
  medical decks cannot move by accident and a deck switches with one attribute. **Alternatives considered:** marker
  only (a medical deck holding the Breathe CSS would flip), declaration only (a pasted style block would not be
  recognised). **Source:** design. **Evidence:** `deck/__init__.py:100`, `pptx_style.py:387`.
- **DEC-002:** keep the `--med-*` tokens and `med-*` classes in Breathe. **Obliged by:** FR-NEW-020.
  **Rationale:** one attribute switch, zero rename risk before the 2026-11-15 talk. **Alternatives considered:**
  `br-` prefix (180 renames, breaks FR-NEW-020). **Source:** user brief (design choice left to the agent).
  **Evidence:** class inventory of the source template (180 distinct classes).
- **DEC-003:** placement of `breathe` right after `medical` in the registry, and `_THEME_PRIORITY` untouched (the
  Breathe check runs before the loop). **Obliged by:** FR-NEW-001, FR-NEW-019. **Rationale:** listing order and
  zero change to the three existing detectors. **Alternatives considered:** append at the end (listing order of
  the spec). **Source:** spec. **Evidence:** `charters.py:26`.
- **DEC-004:** Breathe foreign classes are the Carbon/EI prefixes plus the medical structure names (`med-band`,
  `med-rule`, `med-head`, `med-foot`, `slide-body`, `slide-h1`, `slide-eyebrow`) instead of a prefix. **Obliged
  by:** FR-NEW-011. **Rationale:** both charters share `med-`. **Alternatives considered:** a whitelist of the 180
  Breathe classes (every new class would be an L007 error). **Source:** design. **Evidence:** class inventories.
- **DEC-005:** painted export inside `to_pptx`, after the flowed build, for Breathe decks only; the flowed build
  with `_chrome_breathe` (slide colour and background picture, content flowed) is the degraded result.
  **Obliged by:** FR-NEW-014, FR-NEW-016, FR-NEW-022. **Rationale:** one code path for CLI, tool and editor; the
  PPTX exists before Chromium is touched. **Alternatives considered:** post export command (two steps), a picture
  per slide (not editable). **Source:** design, source template `breathe_pptx.py`.
- **DEC-006:** measures with Playwright's Chromium in a 1600 x 1000 viewport at scale 1, every request to
  `http(s)` aborted (no network, NFR-003 spirit), slide shown with the render's `SHOW_SLIDE_JS`, measure script
  ported from `breathe_pptx.py` with: slide selected by position among outermost slides, any `url(...)` accepted,
  pictures read from data URIs or `file://` paths, remote and vector pictures skipped with the existing warnings.
  **Obliged by:** FR-NEW-014, FR-NEW-007 (linked pictures must paint). **Alternatives considered:** the deck's
  `goToSlide` (not every deck has it). Each slide measure is bounded to 30 s; any Playwright error or timeout
  after launch gives the reason `the render failed: <first line>` and the whole deck keeps the degraded slides.
  **Source:** `render/scripts.py:11`, `breathe_pptx.py:520`.
- **DEC-007:** notes stay written by the existing `_write_notes` (the painter clears shapes, not the notes
  slide). **Obliged by:** FR-NEW-015, SPEC-0022/FR-6. **Rationale:** text unchanged, one writer. **Alternatives
  considered:** the source script's paragraph joining (changes the text). **Source:** `to_pptx.py:193`.
- **DEC-008:** deck files served by a last resort branch of `do_GET` after the gate, containment by resolved path,
  hidden segments and NUL refused, suffix allow list on requested and resolved names. **Obliged by:** FR-NEW-009,
  FR-NEW-010, NFR-003. **Alternatives considered:** a `/deck/` prefix route (relative URLs in the deck would not
  resolve without rewriting the HTML); a `<base>` injection (changes the served bytes). **Source:** design.
- **DEC-009:** `breathe-inline` is a Python service (`breathe/inline.py`) behind a CLI command; the catalogue
  folder is the bundled one (`templates._repo_templates_dir() / "assets" / "breathe"`, the copy shipped with the
  installed package), never the user's templates folder; checks run in the spec order (missing, template file,
  UTF-8, block, names, links leaving `assets`, not found) before any read of an asset or any write; the deck is
  written with `atomic_write(reason="breathe-inline")` so the previous version is in the history (no entry when
  the bytes are equal, `atomic_write` returns False). Asset names must match `[A-Za-z0-9_-][A-Za-z0-9._-]*`
  (FR-NEW-023); a file of the deck's `assets` folder, or a copy destination there, whose resolved path leaves the
  folder refuses (FR-NEW-025, checked with `Path.resolve()` and `is_relative_to`).
  **Obliged by:** FR-NEW-006 to FR-NEW-008, NFR-007. **Alternatives considered:** shipping the source script as a
  tool (not installed with the product). **Source:** `fileio.py:49`, `templates.py:34`.
- **DEC-010:** Pillow declared in the dev dependency group (already locked through python-pptx). **Obliged by:**
  FR-NEW-017. **Rationale:** the generator is a maintainer tool; the runtime already has Pillow. **Alternatives
  considered:** runtime dependency (no runtime use). **Source:** `uv.lock:1349`.
- **DEC-011:** add `.gitattributes` with the house LFS rules before the first binary; `git lfs install --local`.
  **Obliged by:** FR-NEW-017 (catalogue), constraint 3.3. **Source:** house git rule.
- **DEC-012:** the source `verify.sh` and `collage.sh` are not shipped: verification is `lint`, `render
  --report-only`, `export pptx` (now painted) and documented soffice commands in the skill topic; the collage tool
  is talk specific. **Obliged by:** n/a (no code impact): scope 3.2. **Source:** design.
- **DEC-013:** WCBIP based tests copy the private deck when present and skip otherwise. **Obliged by:**
  FR-NEW-020. **Rationale:** the deck holds clinical pictures and is not in this repository. **Source:** design.
- **DEC-014:** the generator gains `--only <name,...>` (subset by output name) for fast tests; the full run is a
  `slow` test. **Obliged by:** FR-NEW-017, constitution (60 s per test). **Source:** `pyproject.toml` timeout.
- **DEC-015:** the Breathe picker set is a generated block of `slide-layouts.js` placed before the medical set,
  between `/* breathe-layouts:begin */` and `/* breathe-layouts:end */`, written by `tools/sync_breathe_layouts.py`
  from the reference deck (slides with `{{ID}}` ids, page numbers `{{N}}`, data URIs of `img[data-asset]`
  emptied, JSON string literals), checked by `make check-generated`. **Obliged by:** FR-NEW-005. **Rationale:**
  one source (the reference), no 14th script in the editor page. **Alternatives considered:** hand written set
  (drifts), a separate script file (changes the script order contract of `test_static_scripts.py`).
- **DEC-016:** the Breathe reference deck and starting point keep their decoration inline (data URIs), so they
  open and render anywhere. `breathe-inline` refuses template files (spec FR-NEW-008), so
  `tools/sync_breathe_layouts.py` refreshes them by calling the service with `allow_template=True`, then writes the
  picker block; its `--check` compares all three without writing.
  **Obliged by:** FR-NEW-002, FR-NEW-004. **Alternatives considered:** linked catalogue (the reference folder is
  not the catalogue folder, so the editor could not show it).
- **DEC-017:** the per deck `F` key line of the source template is removed (the presenter block owns F, SPEC-0022)
  and the presenter block is added by `make sync-deck-pointer`. **Obliged by:** FR-NEW-021.
